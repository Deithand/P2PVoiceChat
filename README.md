# P2P Голосовой чат на C++

Это простое консольное приложение для P2P-голосового общения, созданное на C++.

## Возможности

-   **Аудио:** Использует библиотеку `PortAudio` для кросс-платформенного доступа к микрофону и динамикам.
-   **Сжатие:** Использует аудиокодек `Opus` для эффективного сжатия голосовых данных в реальном времени.
-   **Сеть:** Обмен данными происходит по протоколу UDP с использованием стандартных сокетов.
-   **Архитектура:** Приложение имеет многопоточную архитектуру для одновременной обработки записи, воспроизведения, отправки и получения данных.

## Сборка

### 1. Установка зависимостей

Для сборки проекта вам понадобятся `g++`, `cmake`, `make`, а также библиотеки `PortAudio` и `Opus`.

На системах Debian/Ubuntu их можно установить командой:
```bash
sudo apt-get update
sudo apt-get install -y build-essential cmake portaudio19-dev libopus-dev
```

### 2. Сборка проекта

Для компиляции проекта выполните следующие команды в корневой директории:
```bash
mkdir build
cd build
cmake ..
make
```
Исполняемый файл `voice_chat` появится в директории `build`.

## Использование

Для запуска чата вам понадобится два экземпляра приложения, запущенных на двух компьютерах в одной сети (или на одном компьютере для теста).

Запустите приложение, указав IP-адрес и порт вашего собеседника. Оба пользователя должны запустить приложение, указывая друг на друга.
```bash
# Пример: вы находитесь на 192.168.1.10, а ваш собеседник на 192.168.1.11
./build/voice_chat 192.168.1.11 8888
```
Ваш собеседник должен будет запустить:
```bash
# Пример: собеседник находится на 192.168.1.11, а вы на 192.168.1.10
./build/voice_chat 192.168.1.10 8888
```
Приложение использует порт `8888` для прослушивания. Нажмите `Enter` в консоли, чтобы завершить сеанс.

## Сборка под Windows (с использованием vcpkg)

### 1. Установка зависимостей

1.  **Visual Studio:** Установите [Visual Studio](https://visualstudio.microsoft.com/) с компонентом "Разработка классических приложений на C++".
2.  **vcpkg:** Установите менеджер пакетов [vcpkg](https://vcpkg.io/en/getting-started.html), следуя официальной инструкции.
3.  **Установка библиотек:** С помощью vcpkg установите `PortAudio` и `Opus`.
    ```bash
    vcpkg install portaudio:x64-windows libopus:x64-windows
    ```

### 2. Сборка проекта

Для компиляции проекта необходимо указать CMake, где находится `vcpkg`.

```bash
# Замените [path-to-vcpkg] на ваш путь к vcpkg
cmake -B build -S . -DCMAKE_TOOLCHAIN_FILE=[path-to-vcpkg]/scripts/buildsystems/vcpkg.cmake

# Сборка
cmake --build build
```
Исполняемый файл `voice_chat.exe` появится в директории `build/Debug` или `build/Release`.
